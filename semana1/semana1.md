# Semana 1: Fundamentos de React y TypeScript

## Día 1: Configura tu entorno de desarrollo con Vite y TypeScript
- **Descripción:** Instala y configura Vite junto con TypeScript para crear un nuevo proyecto de React. Explora la estructura del proyecto y familiarízate con la configuración básica.
- **Objetivo:** Crear un nuevo proyecto de React con Vite y TypeScript, asegurándote de que se ejecute correctamente en el navegador.

## Día 2: Escribe y renderiza tu primer componente React con JSX y TypeScript
- **Descripción:** Crea un componente funcional simple en React que muestre un mensaje de bienvenida. Utiliza TypeScript para tipar las props si es necesario.
- **Objetivo:** Entender cómo se escribe un componente en React con TypeScript y cómo se renderiza en el navegador.

## Día 3: Crea un componente de lista que acepte props con tipado TypeScript
- **Descripción:** Desarrolla un componente que liste elementos (por ejemplo, una lista de nombres o tareas). Usa TypeScript para definir el tipo de las props que recibe el componente, asegurando un uso correcto de los datos.
- **Objetivo:** Aprender a pasar y validar props en un componente React utilizando TypeScript.

## Día 4: Crea un contador con TypeScript que aumente al hacer clic en un botón
- **Descripción:** Implementa un contador que incremente su valor cada vez que se haga clic en un botón. Usa el hook `useState` y asegúrate de que el estado y sus métodos estén correctamente tipados con TypeScript.
- **Objetivo:** Comprender el manejo del estado en componentes funcionales con hooks y TypeScript.

## Día 5: Crea un formulario con TypeScript que muestre una alerta con el texto ingresado
- **Descripción:** Diseña un formulario simple con un campo de texto y un botón de envío. Al enviar el formulario, muestra una alerta con el texto ingresado. Utiliza TypeScript para manejar los tipos de los eventos y los estados.
- **Objetivo:** Manejar eventos de formulario y estados en React con TypeScript.

## Día 6: Muestra diferentes componentes con TypeScript dependiendo del estado
- **Descripción:** Crea una interfaz que cambie entre diferentes componentes basados en el estado de la aplicación. Por ejemplo, mostrar un componente de "Inicio de sesión" o "Perfil de usuario" dependiendo de si el usuario está autenticado o no.
- **Objetivo:** Practicar el renderizado condicional y el manejo de estados complejos con TypeScript.

## Día 7: Crea una pequeña aplicación con React y TypeScript
- **Descripción:** Utiliza los conceptos aprendidos durante la semana para construir una pequeña aplicación. Podría ser una lista de tareas, un contador de clics, o cualquier otra aplicación que demuestre el uso de componentes, estado, y eventos.
- **Objetivo:** Consolidar los conocimientos adquiridos y aplicarlos en un proyecto pequeño pero completo.
