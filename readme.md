# Plan de Estudio de React con TypeScript - 1 Mes

## Semana 1: Fundamentos de React y TypeScript

### Día 1: Introducción a React y TypeScript

- **Temas:** ¿Qué es React? ¿Por qué usar React? Introducción a TypeScript en React
- **Leer:** [Documentación oficial de React - "Hola Mundo"](https://es.reactjs.org/docs/hello-world.html), [Introducción a TypeScript en React](https://www.typescriptlang.org/docs/handbook/react.html)
- **Ejercicio:** Configura tu entorno de desarrollo con Vite y TypeScript (en lugar de Create React App)

### Día 2: JSX y TypeScript

- **Temas:** Entender JSX con TypeScript, diferencias con HTML
- **Leer:** [Documentación oficial - "Introducción a JSX"](https://es.reactjs.org/docs/introducing-jsx.html), [TypeScript con JSX](https://www.typescriptlang.org/docs/handbook/jsx.html)
- **Ejercicio:** Escribe y renderiza tu primer componente React con JSX y TypeScript

### Día 3: Componentes, Props y TypeScript

- **Temas:** Componentes Funcionales vs. Componentes de Clase, Props con TypeScript
- **Leer:** [Documentación oficial - "Componentes y Props"](https://es.reactjs.org/docs/components-and-props.html), [Uso de TypeScript con Props](https://www.typescriptlang.org/docs/handbook/react-&-webpack.html)
- **Ejercicio:** Crea un componente de lista que acepte props con tipado TypeScript

### Día 4: Estado, Ciclo de Vida y TypeScript

- **Temas:** Estado en componentes de clase, uso de `useState` en componentes funcionales, todo con TypeScript
- **Leer:** [Documentación oficial - "Estado y Ciclo de Vida"](https://es.reactjs.org/docs/state-and-lifecycle.html), [TypeScript y Estado en React](https://www.typescriptlang.org/docs/handbook/react-&-webpack.html#stateful-components)
- **Ejercicio:** Crea un contador con TypeScript que aumente al hacer clic en un botón

### Día 5: Manejo de Eventos con TypeScript

- **Temas:** Eventos en React con TypeScript
- **Leer:** [Documentación oficial - "Manejando Eventos"](https://es.reactjs.org/docs/handling-events.html), [Eventos en TypeScript](https://www.typescriptlang.org/docs/handbook/react-&-webpack.html#typing-events)
- **Ejercicio:** Crea un formulario con TypeScript que muestre una alerta con el texto ingresado

### Día 6: Renderizado Condicional y TypeScript

- **Temas:** Uso de condicionales en JSX con TypeScript
- **Leer:** [Documentación oficial - "Renderizado Condicional"](https://es.reactjs.org/docs/conditional-rendering.html)
- **Ejercicio:** Muestra diferentes componentes con TypeScript dependiendo del estado

### Día 7: Repaso y Proyecto Pequeño con TypeScript

- **Actividad:** Repasa los conceptos de la semana
- **Proyecto:** Crea una pequeña aplicación con React y TypeScript que utilice los conceptos aprendidos

## Semana 2: Profundizando en React y TypeScript

### Día 8: Listas, Keys y TypeScript

- **Leer:** [Documentación oficial - "Listas y Keys"](https://es.reactjs.org/docs/lists-and-keys.html)
- **Ejercicio:** Renderiza una lista de datos con TypeScript

### Día 9: Formularios y TypeScript

- **Leer:** [Documentación oficial - "Formularios"](https://es.reactjs.org/docs/forms.html)
- **Ejercicio:** Crea un formulario de registro con TypeScript

### Día 10: Elevación de Estado y TypeScript

- **Leer:** [Documentación oficial - "Elevando el Estado"](https://es.reactjs.org/docs/lifting-state-up.html)
- **Ejercicio:** Comparte el estado entre componentes hermanos con TypeScript

### Día 11: Composición vs Herencia y TypeScript

- **Leer:** [Documentación oficial - "Composición vs Herencia"](https://es.reactjs.org/docs/composition-vs-inheritance.html)
- **Ejercicio:** Refactoriza un componente para usar composición con TypeScript

### Día 12: Pensando en React con TypeScript

- **Leer:** [Documentación oficial - "Pensando en React"](https://es.reactjs.org/docs/thinking-in-react.html)
- **Proyecto:** Comienza a planificar una aplicación más compleja con TypeScript

### Día 13-14: Construye una Aplicación Pequeña con TypeScript

- **Actividad:** Utiliza lo aprendido para construir una aplicación pequeña con React y TypeScript

## Semana 3: Hooks, Contexto y TypeScript

### Día 15-17: Hooks y TypeScript

- **Temas:** `useState`, `useEffect`, `useContext` con TypeScript
- **Leer:** [Documentación oficial - "Hooks"](https://es.reactjs.org/docs/hooks-intro.html), [Hooks con TypeScript](https://www.typescriptlang.org/docs/handbook/react-&-webpack.html#hooks)
- **Ejercicio:** Refactoriza componentes de clase a componentes funcionales usando Hooks y TypeScript

### Día 18-19: Contexto y TypeScript

- **Leer:** [Documentación oficial - "Contexto"](https://es.reactjs.org/docs/context.html)
- **Ejercicio:** Crea un tema oscuro/claro para tu aplicación con TypeScript

### Día 20-21: Proyecto con Hooks, Contexto y TypeScript

- **Proyecto:** Implementa una característica en tu aplicación usando Hooks, Contexto y TypeScript

## Semana 4: Avanzado y Proyecto Final con TypeScript

### Día 22-23: React Router y TypeScript

- **Leer:** [Documentación de React Router](https://reactrouter.com/web/guides/quick-start)
- **Ejercicio:** Añade navegación a tu aplicación con TypeScript

### Día 24-25: Llamadas a API y TypeScript

- **Temas:** Uso de `fetch` o `axios` con TypeScript para llamadas a API
- **Ejercicio:** Conecta tu aplicación con una API externa usando TypeScript

### Día 26-27: Mejores Prácticas y Optimización con TypeScript

- **Leer:** Artículos sobre mejores prácticas en React y TypeScript
- **Ejercicio:** Optimiza tu aplicación con TypeScript (uso de `React.memo`, `useCallback`, etc.)

### Día 28-30: Proyecto Final con TypeScript

- **Desarrolla:** un proyecto final que incorpore todo lo aprendido con React y TypeScript
- **Sugerencia:** Una aplicación CRUD (Crear, Leer, Actualizar, Eliminar) con conexión a una API y TypeScript
