# Semana 2: Profundizando en React y TypeScript

## Día 8: Listas, Keys y TypeScript
- **Descripción:** Aprende a renderizar listas de elementos en React utilizando TypeScript. Utiliza el concepto de 'keys' para optimizar el renderizado de listas.
- **Objetivo:** Renderizar una lista de elementos (como nombres o tareas) y entender la importancia de las 'keys' en React.

## Día 9: Formularios y TypeScript
- **Descripción:** Crea un formulario más complejo que incluya varios tipos de inputs. Utiliza TypeScript para manejar el estado del formulario y validar los datos ingresados.
- **Objetivo:** Manejar formularios complejos y validación de datos con TypeScript en React.

## Día 10: Elevación de Estado y TypeScript
- **Descripción:** Aprende a "elevar" el estado a componentes padres para compartir datos entre componentes hermanos. Utiliza TypeScript para asegurar la correcta tipificación a lo largo de los componentes.
- **Objetivo:** Compartir estado entre componentes hermanos y entender el concepto de elevación de estado en React con TypeScript.

## Día 11: Composición vs Herencia y TypeScript
- **Descripción:** Explora los patrones de diseño de composición y herencia en React, y cómo TypeScript puede ayudar a implementarlos de manera efectiva.
- **Objetivo:** Entender y aplicar los conceptos de composición y herencia en componentes React con TypeScript.

## Día 12: Pensando en React con TypeScript
- **Descripción:** Planifica y comienza a desarrollar una aplicación más compleja, aplicando los principios de "Pensando en React". Utiliza TypeScript para estructurar tu aplicación de manera eficiente.
- **Objetivo:** Aplicar un enfoque metodológico para la construcción de aplicaciones en React con TypeScript.

## Día 13-14: Construye una Aplicación Pequeña con TypeScript
- **Descripción:** Utiliza lo aprendido para construir una aplicación pequeña pero más compleja que en la semana anterior. Podría ser una aplicación de lista de tareas con funcionalidades adicionales, una pequeña tienda en línea, etc.
- **Objetivo:** Desarrollar una aplicación que integre los conceptos aprendidos hasta ahora, con un enfoque en la arquitectura y el flujo de datos.
