# Semana 3: Hooks, Contexto y TypeScript

## Día 15: Introducción a Hooks con TypeScript
- **Descripción:** Aprende sobre los Hooks en React, comenzando con `useState` y `useEffect`. Utiliza TypeScript para tipar correctamente los estados y efectos.
- **Objetivo:** Comprender y aplicar los hooks básicos (`useState` y `useEffect`) en componentes funcionales con TypeScript.

## Día 16: Hooks Personalizados y TypeScript
- **Descripción:** Crea tus propios hooks personalizados para encapsular lógicas de componentes. Aprende a tipar adecuadamente tus hooks con TypeScript.
- **Objetivo:** Desarrollar y utilizar hooks personalizados, mejorando la reutilización de código y la organización en tus proyectos React.

## Día 17: `useContext` y Manejo de Estado Global con TypeScript
- **Descripción:** Explora el hook `useContext` para manejar un estado global en tu aplicación. Utiliza TypeScript para asegurar un manejo de tipos consistente a través del contexto.
- **Objetivo:** Implementar un estado global en una aplicación React utilizando `useContext` y TypeScript.

## Día 18: `useReducer` y TypeScript
- **Descripción:** Aprende a utilizar `useReducer` para un manejo de estado más complejo. Combina `useReducer` con `useContext` para un estado global más robusto.
- **Objetivo:** Manejar estados complejos con `useReducer` y entender su integración con `useContext` en aplicaciones React con TypeScript.

## Día 19: `useRef` y `useMemo` con TypeScript
- **Descripción:** Descubre cómo utilizar `useRef` para acceder a elementos del DOM y mantener referencias inmutables. Aprende a usar `useMemo` para optimizar el rendimiento de tus componentes.
- **Objetivo:** Aplicar `useRef` para manipulaciones del DOM y `useMemo` para optimización de rendimiento en React con TypeScript.

## Día 20: `useCallback` y Optimización de Componentes con TypeScript
- **Descripción:** Utiliza `useCallback` para optimizar el rendimiento de tus componentes, especialmente en situaciones donde se pasan callbacks a componentes hijos.
- **Objetivo:** Mejorar el rendimiento de los componentes evitando renderizados innecesarios mediante el uso de `useCallback` en React con TypeScript.

## Día 21: Proyecto con Hooks, Contexto y TypeScript
- **Descripción:** Implementa una característica en tu aplicación (como un cambio de tema, paginación, filtrado de datos) usando Hooks y Contexto con TypeScript.
- **Objetivo:** Consolidar los conocimientos adquiridos sobre Hooks y Contexto en un proyecto práctico, aplicando TypeScript para un manejo de tipos eficiente.
